# Image sources

The page templates use remote, resized illustrative photographs from Unsplash via `images.unsplash.com` URLs embedded directly in the HTML. They are not bundled downloads. The image fallback styling in `css/style.css` provides a neutral treatment if an image cannot load.

These photos illustrate school-like spaces and activities; they do not represent or verify facilities at a real EAK school. For an offline or production deployment, replace the remote URLs with appropriately licensed local images and retain descriptive alt text.
